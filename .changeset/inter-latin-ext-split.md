Inter: the Latin Extended face a page preloads and waits for is 19 kB instead of 85 kB. `inter-latin-ext.woff2` now holds Latin Extended-A (U+0100-017F: every Czech, Slovak, Polish, German and Hungarian letter; the sites use 31 code points of the old file's 733, all in this block), and the rest of the old file is a third face, `inter-latin-ext-rest.woff2`, that only a page showing such a glyph fetches. The glyphs, variations, layout rules, glyph names and base glyphs are the old file's, regrouped (`scripts/split-latin-ext.py`); the names and base glyphs stay because Chrome on macOS anti-aliases small text differently without them. A browser test (`catalog/tests/fonts.spec.ts`) compares the pair with the full file glyph by glyph at ten sizes, four weights and three pixel densities, byte for byte. Sites keep their preload list and Early Hints as they are (same two file names); the integration copies the third file by its `inter-` prefix. A site with its own `@font-face` rules (www) declares the third face itself.

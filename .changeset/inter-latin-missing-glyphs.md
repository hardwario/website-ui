Inter: five characters the copy uses are part of the Latin face now: the non-breaking hyphen (U+2011, "1‑Wire"), → (U+2192), ↗ (U+2197), ₂ (U+2082) and the Greek μ (U+03BC). The Google Fonts `latin` subset holds none of them, so a browser set them in a system font in the middle of an Inter line. The arrows, the subscript and the mu are cut from the full Inter file of the same build (4.001), the way the Google subset was cut (`scripts/extend-latin.py`). The non-breaking hyphen is drawn with the glyph of the keyboard hyphen, not with Inter's own shorter hyphen (owner ruling 2026-11-11), so "RS‑485" and "low-power" carry the same stroke. The script proves before it writes that every glyph of the old face keeps its outline, advance and side bearing at seven weights, and `catalog/tests/fonts.spec.ts` compares the new face with the Google subset in a browser, byte for byte (216 glyphs and a line of text at ten sizes, four weights and three pixel densities). The file grows from 48.4 to 48.9 kB. Visible change: the five characters look like Inter, the arrow of `HWioStoryCard` among them. Sites need no change: the face's `unicode-range` in the generated CSS names the new code points. A browser that has the old file in its cache (the font URLs are immutable for a year) keeps showing the system font for the five until its copy turns over. A site with its own `@font-face` rules (www) regenerates its own file with the script and extends its range.

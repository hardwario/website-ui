The HARDWARIO themes follow the Brand Guidelines HBG.261028.01 revision 3 (issued 2026-10-30, the rules of revision 2), which are now the master for the web.

- `@hubpav/hwio-brand`: `brand.json` carries the guidelines' palette under their names (Red, Blue, Navy, Sky, Gray, Ink, Panel, Mist, Hairline, Green, Amber and the dark-mode set of D35), the gradient and its figure variant (D1, D23, D33), the web grid (12 columns, 1 280 px, 24 px gutters), breakpoints, motion timings, icon and chart rules. Themes pick a typography preset and a layout preset; `hwio` uses the guidelines' web type scale (H1 60-72 px Bold, H2 40-48 px and H3 28-32 px Semibold, kicker 13 px Bold caps, body 16 px; line heights 1.2 / 1.3 / 1.4 at least; no Medium), `er3o` keeps direction A unchanged. `hwio`: primary Blue `#016ad4` (was Navy, R1), secondary Navy, neutrals Panel and Hairline, status Green, Amber, Red and Info in Blue, secondary text in Gray. `hwio-dark`: D35 (ground `#16161d`, Ink surfaces, White text, light gray secondary text, Sky primary and links, light red accent, light status colours). New `scripts/contrast.mjs` and a test that computes every theme's text/background pairs. DESIGN.md regenerated.
- `@hubpav/hwio-ui`: theme files carry `--hwio-type-*`, `--hwio-weight-*`, `--hwio-gradient*`, `--hwio-chart-*`, `--hwio-motion-*`, `--hwio-icon`, `--hwio-text-secondary` and the grid variables; `styles.css`, `prose.css` and the components read them, with the previous values as fallbacks, so `er3o` renders unchanged. Kickers are caps on the HARDWARIO themes, light gray on Ink; header nav Regular, labels Bold, icons Navy (White in dark); the reveal runs 400 ms; the consent texts drop their 80 % opacity (the policy link reached only 3.7:1); DaisyUI table heads in secondary text (were 4.1:1). New classes `hwio-caption`, `hwio-figure`, `hwio-icon`, `hwio-icon-tile`, `hwio-link`, `hwio-note`, `hwio-weight-*`, `hwio-choice-title`. Sites adopt this version with their relaunch; a site's own `--hwio-container: 1280px` override narrows the guidelines' grid and should be dropped then.
